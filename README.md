# TSI (Toggle-Sprint-Indicator) 
A lightweight, clean Fabric mod for Minecraft that provides a helpful visual indicator when you are sprinting.

## Features
* **Clear Indicator:** Know your exact sprint state at a glance.
* **Fabric Native:** Built for performance using the Fabric loader.
* **Lightweight:** Zero bloat, designed for smooth PVP and survival gameplay.

## Requirements
* Minecraft (Fabric Loader)
* Java 25 (for building)
